# Design principles and tokens

## Principles

1. **Distinct by composition, not by colour.** Two brands should differ in _what the page is made of_: which hero, which
   proof, where the weight sits, which signature section. The palette comes last. The three reference sites are built
   on the same ~4,900-line kit (12–17 kit components each, plus 500–1,400 lines of site code for brand, signature
   sections and styling) and look like three companies.
2. **Content first, chrome second.** Every section has a heading and a job. Decoration (photos held back under a scrim,
   orbit lines, highlighter stripes) supports the words and never carries meaning alone.
3. **Accessible by construction.** Contrast is a test, not a review comment. Focus is always visible. Native elements
   (`<dialog>`, `<details>`, radios, `<table>`) are used for their semantics. Anything a pointer can do, a keyboard can.
4. **Fast by default.** Static HTML, under 1 KB of gzipped script per page, real images in modern formats, fonts
   self-hosted and subset. Performance is the baseline, not a feature.
5. **Two directions, one layout.** Logical properties everywhere; RTL is not a variant to maintain.
6. **Tokens over overrides.** A brand changes variables, not markup. Sites can still write CSS (the `site` layer)
   when a gesture is truly theirs.
7. **Truthful content.** Sample data is labelled. Facts that aren't verified aren't published. A closing section always
   offers an action.

## Token reference

All tokens are CSS custom properties generated by `compileBrand()` from `src/brand.ts`. Components read only these.

### Tone roles (re-declared per `data-tone`)

| Token                                       | Brand field                                  | Use                                       | Contrast gate                       |
| ------------------------------------------- | -------------------------------------------- | ----------------------------------------- | ----------------------------------- |
| `--tone-bg`                                 | `bg`                                         | Section ground                            | —                                   |
| `--tone-bg-image`                           | `bgImage`                                    | Optional gradient/texture over the ground | checked against `bg`                |
| `--tone-fg`                                 | `fg`                                         | Body text                                 | ≥ 4.5 on `bg`                       |
| `--tone-heading`                            | `heading` (default `fg`)                     | h1–h4, step titles, stat figures          | ≥ 4.5 on `bg` and `surface`         |
| `--tone-fg-muted`                           | `fgMuted`                                    | Secondary text                            | ≥ 4.5 on `bg`                       |
| `--tone-line`                               | `line`                                       | Hairlines, dividers                       | advisory                            |
| `--tone-accent`                             | `accent`                                     | Primary action fill, "current" marks      | edge advisory (3:1)                 |
| `--tone-on-accent`                          | `onAccent`                                   | Text/icons on accent                      | ≥ 4.5 on `accent` and `accentHover` |
| `--tone-accent-hover`                       | `accentHover` (default `accent`)             | Hover/pressed primary                     | —                                   |
| `--tone-accent-text`                        | `accentText` (default `accent`)              | Accent as text (links, highlighted words) | ≥ 4.5 on `bg`                       |
| `--tone-ring`                               | `ring`                                       | Focus indicator                           | ≥ 3 on `bg` and `surface`           |
| `--tone-surface`                            | `surface`                                    | Cards, panels, inputs                     | —                                   |
| `--tone-surface-fg` / `-fg-muted` / `-line` | `surfaceFg`, `surfaceFgMuted`, `surfaceLine` | Content on surfaces                       | ≥ 4.5 on `surface`                  |
| `--tone-highlight` / `--tone-on-highlight`  | `highlight`, `onHighlight`                   | Markers, selection, badges                | ≥ 4.5 together                      |

`color-scheme` is set per tone too, so native controls and scrollbars match a dark section.

### Typography

| Token                                                                                                  | Source                                                                                            |
| ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------- |
| `--font-display`, `--font-body`, `--font-mono`                                                         | `type.families` (per-locale overrides in `type.locales`)                                          |
| `--font-label`, `--font-control`                                                                       | `type.label.family`, `control.family`                                                             |
| `--step--2` … `--step-7`                                                                               | Fluid scale: `clamp()` from `minBase × minRatio^n` at 360 px to `maxBase × maxRatio^n` at 1280 px |
| `--step-display`, `--step-label`                                                                       | `type.displayStep`, `type.label.step`                                                             |
| `--weight-*`, `--leading-*`, `--tracking-*`, `--transform-*` for `display`, `heading`, `body`, `label` | `type.display/heading/body/label`                                                                 |

Caseless scripts (Arabic, Hebrew, Persian, Urdu, CJK, Thai, Hindi) get `tracking: 0` and `transform: none` automatically
for every role and for controls.

Utility classes: `.lk-text-display`, `.lk-text-h1`…`.lk-text-h4`, `.lk-text-lead`, `.lk-text-small`, `.lk-text-muted`,
`.lk-text-accent`, `.lk-eyebrow`, `.lk-mark`, `.lk-tabular`, `.lk-ltr`.

### Space and layout

| Token                         | Meaning                                                                                      |
| ----------------------------- | -------------------------------------------------------------------------------------------- |
| `--space-3xs` … `--space-3xl` | Fluid space scale: 0.25× to 6× the body size                                                 |
| `--section-pad`               | Section block padding, from `space.density` (compact 3→5×, comfortable 4→7×, airy 5→9× body) |
| `--section-gap`               | Gap between a section header and its content                                                 |
| `--container`, `--gutter`     | Max content width and fluid inline margin                                                    |
| `--header-height`             | Header bar height; used for scroll padding and overlay heroes                                |

Layout classes: `.lk-container` (`data-width="narrow|wide"`), `.lk-stack`, `.lk-cluster`, `.lk-grid` (`--lk-min`,
`--lk-gap`), `.lk-visually-hidden`.

### Shape, depth, motion, controls

| Token                                                                               | Source                                                                                           |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `--radius-control`, `--radius-card`, `--radius-media`, `--radius-badge`             | `shape`                                                                                          |
| `--border-width`, `--card-border-width`                                             | `shape.border` (hard elevation forces ≥ 2px cards)                                               |
| `--shadow-card`, `--shadow-raised`, `--shadow-press`                                | `elevation.style`: `flat` (none), `soft` (diffuse, `tint`), `hard` (solid offset in `--tone-fg`) |
| `--motion-fast`, `--motion-base`, `--motion-slow`, `--motion-ease`                  | `motion`                                                                                         |
| `--reveal-distance`, `--reveal-from-opacity`                                        | `motion.reveal`: `none`, `fade`, `rise`                                                          |
| `--control-height`, `--control-weight`, `--control-transform`, `--control-tracking` | `control`                                                                                        |

Motion classes: `.lk-enter` (load-time entrance, stagger with `--lk-delay`) and `.lk-reveal` (scroll reveal through
CSS view timelines). Both are disabled under `prefers-reduced-motion: reduce`, and content is visible without them.

## Cascade layers

```
@layer reset, tokens, base, layout, components, sections, utilities, site;
```

Kit styles live in `components` and `sections`. Write site styles in `@layer site { … }` and they win without
`!important`. Unlayered CSS beats all layers, so keep site CSS in the `site` layer too, or it will also beat
`utilities`.
