# 0005 — Locales are URLs; logical properties; typed content parity

**Status:** Accepted · 2026-10-28

## Context

Opera served Arabic and English from one URL selected by a cookie, with no `hreflang` ([audit D2](../research/opera-audit.md)).
Two of the three reference brands are Arabic-first, and one is English-first with an Arabic version. RTL must be correct
by construction, not by per-page fixes.

## Decision

- **Routing.** Each site declares `locales` (code, `dir`, `label`, `hreflang`) and a `defaultLocale`. The default lives at
  `/`, the others at `/<code>/`. One page file renders every locale through `localePaths()` in `getStaticPaths`.
  The `Seo` component emits a self-canonical per locale, `hreflang` alternates for every locale, and `x-default`.
- **Document.** `<html lang dir>` comes from the locale. Language switch links point to the same page in the other locale.
  Their `hreflang` and `lang` attributes are set so screen readers pronounce the label correctly.
- **Layout.** Logical properties only. Directional icons (arrows, chevrons) carry `data-flip` and are mirrored in RTL.
  Logos, media and numerals are never mirrored.
- **Typography.** Brands give per-locale overrides (`type.locales.ar`): families, line-heights, letter-spacing forced to 0,
  label uppercase disabled, and an optional larger type scale for scripts that read smaller. These compile to `:lang(ar)` rules.
- **Bidi.** `<Ltr>` / `.lk-ltr` isolates phone numbers, codes, prices and Latin product names inside RTL text
  (`unicode-bidi: isolate`).
- **Content parity.** Each site defines a `Content` type. `content/ar.ts` and `content/en.ts` must both satisfy it, so a
  missing translation is a compile error, not a blank on the page.

## Consequences

- Each language is indexable and shareable. Lighthouse/SEO checks and the e2e suite assert `hreflang`, `lang` and `dir`.
- No runtime locale detection. A visitor's `Accept-Language` redirect can be added at the edge without touching the
  system (roadmap).
- Authors write two content files per site. That is intended: translation is authored, not machine-filled.
